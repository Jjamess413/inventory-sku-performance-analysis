# Data attribution

Source: Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33

Source page: https://archive.ics.uci.edu/dataset/352/online+retail

Dataset licence: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/

Changes made: transaction classification, merchandise code filtering, complete-month selection, omission of CustomerID, normalisation of identifiers and descriptions, GBP minor-unit conversion, aggregation, derived KPI calculations and a separately labelled synthetic inventory scenario.

The original publisher and dataset creator have not endorsed this project. The dataset licence applies to the source data and its adaptations; it does not imply a licence for unrelated third-party content.

The synthetic balances and supplier assumptions were generated for this portfolio and are not observations from the retailer, James You's employers or his e-commerce business.
